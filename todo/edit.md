# 현재 프로젝트

- TrackBall, TrackBat의 분석 결과는 실제 추적 대상이 아닌 다른 대상을 추적할 수 있음
- 최대 추적값 5개를 저장하고, 나중에 사용자가 지정

# 문제
- 직관적이지 못함
- 모델 통합적이지 못함

# 수정
- slider 아래의 Conf 입력 등은 제거
- 새 분석, 저장, 불러오기 섹션에 편집 섹션을 추가(TrackBall, TrackBat)
- 수정 창에서 추적 결과를 각 프레임마다 보여줌
  - Conf값 입력 등도 여기에
- 각 프레임에서 지정하고자 하는 결과를 선택하면 그 다음 프레임으로 이동
